# Vizia UI

**Summary:** UI patterns for Vizia-based plugin editors.
Covers reactive views, lenses, and model-view separation.
Read this when using Vizia for plugin GUIs.

## Key Rules

- Define models outside the view tree
- Use `Lens` for data access
- Trigger redraws via events
